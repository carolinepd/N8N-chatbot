# My First AI Chatbot Workflow in n8n

I created my first generic AI chatbot using n8n to learn how LLMs and API integrations work. 

### Features & Setup
* **LLM Integration:** Connected to Google AI Studio using Gemini Flash models.
* **API Server Connection:** Configured custom API credentials and webhooks in n8n.
* **Basic Capabilities:** Handles general Q&A and conversational prompts in real-time.

### How to Use
1. Download the `My workflow.json` file from this repository.
2. Import it into your own n8n instance.
3. Add your Google Gemini API key to test the chatbot
